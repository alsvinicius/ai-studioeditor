# Documentação para usar e entender o estúdio

Este mapa separa a documentação por necessidade: aprender um fluxo, executar uma tarefa, consultar fatos de configuração ou entender uma decisão visual. Os registros de produto ficam separados em `docs/product/`, `docs/engineering/` e `docs/planning/`.

## Tutoriais

- [Primeira execução](tutorial-first-run.md): seguir um fluxo simples do início à exportação.

## Guias práticos

- [Instalar e executar localmente](how-to-run.md): preparar dependências e autenticação opcional, e escolher execução no host ou com Compose.
- [Revisar e exportar uma gravação](how-to-review.md): escolher provedor, conferir sugestões, tratar falhas e preparar os arquivos.
- [Verificar Nova gravação com Playwright](how-to-test-new-recording.md): abertura, cancelamento e importação real.
- [Conectar o YouTube](how-to-connect-youtube.md): configurar OAuth e enviar vídeos revisados como privados.
