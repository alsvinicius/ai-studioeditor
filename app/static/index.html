Credencial OAuth

Importe o JSON de um cliente Web criado no Google Cloud para conectar seu canal.

Verificando credencial…

Trocar a credencial exige conectar o canal novamente. O arquivo fica salvo apenas neste estúdio.

Como obter a credencial no Google Cloud
  1. Habilite a YouTube Data API v3 no seu projeto.
  2. Configure o consentimento OAuth e adicione sua conta como usuário de teste, se necessário.
  3. Crie um cliente OAuth do tipo Aplicativo Web.
  4. Adicione o URI de redirecionamento acima e baixe o JSON.
  5. Importe o arquivo aqui e conecte seu canal.
